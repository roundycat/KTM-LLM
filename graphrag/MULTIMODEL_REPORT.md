# 다중 모델 GraphRAG 평가 — 전과목 517문항 (+ 선택적RAG)

각 모델을 **그냥LLM / 그래프RAG / 그래프+해설 / 선택적RAG**로 평가. 
**선택적RAG = 처방형 문항은 그래프RAG, 그 외 문항은 그냥LLM**으로 유형별 라우팅(누수 없음, 고정 규칙).
채점: 예측==정답, Wilson 95% CI.

> 처방형 86문항 / 그 외 431문항. 그래프RAG는 보기 처방의 구성·주치를 KG에서 주입 → **처방형에서만 효과**.
