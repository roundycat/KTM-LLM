# 한의학 국가시험에서의 GraphRAG와 유형-선택적 검색증강 — 논문용 종합 정리

> 본 문서는 **논문 작성용 단일 정리본**이다. 데이터·방법·실험 프로토콜(누수 방지)·결과·한계·재현 정보를
> 빠짐없이 기록한다. 원본 GraphRAG 시스템(KTM-LLM `bigse0u1` 브랜치)의 모든 자료를 통합·확장한다.
> 작성 기준일: 2026-06-14. 평가는 전부 **로컬 추론(Ollama, GPU), 비용 $0**.

---

## 초록 (Abstract)

한의사·한약사 국가시험의 텍스트형 5지선다 **517문항**을 대상으로, 한의학 **처방 지식그래프(Knowledge
Graph)** 기반 검색증강생성(GraphRAG)이 로컬 대형언어모델(LLM)의 정답률을 높이는지 검증한다. 보기에
등장하는 처방을 지식그래프에서 조회해 **구성약재·주치증상·계통**을 근거로 주입하는 GraphRAG는, 전체
517문항 평균으로는 **그냥 풀이(closed-book)와 차이가 거의 없으나**, **처방 선택형 문항에서는 큰 향상**을
보인다(qwen2.5-7B 기준 처방형 +15.1%p). 이로부터 **문항 유형에 따라 검색증강을 선택적으로 적용**하는
*유형-선택적 RAG(selective RAG)* 를 제안한다: 처방형 문항에는 GraphRAG, 그 외에는 그냥 풀이. 이 라우팅은
전체 정답률을 향상시킨다(qwen2.5 48.7%→51.3%, +2.5%p). 모든 평가는 **시험 문항을 학습/구축에 사용하지
않고 최종 테스트에서만** 사용하며, 정답을 분리(누수 방지)한 엄격한 프로토콜을 따른다. 6개 로컬 모델
(qwen2.5·gemma2·exaone3.5·llama3.1·mistral·solar)로 일반화를 검증한다.

## 1. 배경 및 원본 시스템 (`bigse0u1`)

원본 GraphRAG 시스템은 환자 증상→처방 추천을 위해 **Neo4j 지식그래프 + Chroma 벡터검색 + BGE-m3 임베딩**을
결합하고, 국시 517문항으로 **그냥LLM / 벡터RAG / GraphRAG / 보기Graph** 4방식을 비교했다.

**원본 결과(LLM=gpt-4o-mini):**

| 범위 | 그냥LLM | 벡터RAG | GraphRAG | 보기Graph |
|---|---:|---:|---:|---:|
| 전체 517 | 59.6% | 59.6% | 59.2% | **60.0%** |
| 처방형 86 | 30.2% | 29.1% | 31.4% | **34.9%** |

원본의 핵심 관찰: (i) 전체에선 방식 간 차이가 거의 없음(강한 LLM 기저 + 낮은 검색 recall), (ii) **처방형에서
보기Graph가 유일하게 그냥LLM을 상회**(정답이 보기에 있고 그 처방 정보를 그래프에서 정확히 가져올 때만 효과),
(iii) recall@ctx ≈ 4.7%(증상→처방 검색이 정답 처방을 거의 못 찾음).

> 본 연구는 이 시스템의 **데이터·그래프를 그대로 사용**하되, ① 약한 gpt-4o-mini 대신 **로컬 6모델**로 확장,
> ② Neo4j 없이 **순수 Python으로 그래프 검색 재현**(이식성), ③ **유형-선택적 RAG**를 제안·검증한다.

## 3. 방법 — 네 가지 풀이 방식 (구체 예시)

**예시 문항(처방형):** "손발이 차고 가슴이 달아오르며 먹으면 토한다. **치방은?** ①사역탕 ②사역산 ③오매환
④반하사심탕 ⑤복령감초탕" (정답 ③)

| 방식 | LLM이 보는 입력 | 설명 |
|---|---|---|
| **① 그냥LLM** | 문제 + 보기 | 근거 없이 모델 지식만으로 풀이(폐쇄형, closed-book) |
| **② 그래프RAG** | 문제 + 보기 + **보기 5개 처방의 구성·주치·계통**(그래프 조회) | 예: "오매환—주치 궐음병 상열하한, 구성 오매·세신·건강·황련…" 을 근거로 주입 → ③ 선택 용이 |
| **③ 그래프+해설** | ② + **유사한 다른 문항의 풀이(해설)** | 해설은 자기 문항 제외(LOO). **누수·무효과로 최종 제외**(4.3) |
| **④ 선택적RAG** | (유형 따라) ② 또는 ① | **규칙**: 처방형이면 ②그래프RAG, 그 외면 ①그냥LLM 결과 사용 |

- 그래프 조회(보기Graph 방식): 보기에서 처방명 추출(합방 " 합 " 분리) → 지식그래프에서 해당 처방의
  구성약재·주치증상·계통을 가져와 근거 블록 구성. **정답은 사용하지 않음**.
- 디코딩: temperature 0(결정론적), 출력은 정답 번호 추출(`정답: N`/`N번`/독립숫자 견고 파싱).

## 4. 실험 프로토콜 — 데이터 누수 방지 (핵심)

**원칙: 시험 문항은 학습/구축에 사용하지 않고, 최종 테스트에서만 사용한다. 정답은 어떤 단계에서도 모델에
주지 않는다.**

| 구성요소 | 시험 문항/정답을 썼나 | 판정 |
|---|---|---|
| 지식그래프·처방/용어 청크 | ❌ 교과서·용어집으로 구축, 문항 무관 | ✅ 깨끗 |
| **① 그냥LLM** | 테스트 시 문항만(정답 분리) | ✅ 깨끗 |
| **② 그래프RAG** | 테스트 시 문항의 *보기 처방*을 교과서 그래프에서 조회(오픈북). 정답 미사용 | ✅ 깨끗 |
| **④ 선택적RAG** | ①·②로만 구성 | ✅ 깨끗 |
| ③ 그래프+해설 | ⚠️ 해설을 **정답을 보고 사전 생성** → 시험 정답 사전 사용 | ❌ 원칙 위반 |

### 4.1 파인튜닝(학습) 없음
6개 모델을 **그대로(폐쇄형 base) 추론만** 한다. 문항으로 가중치를 갱신하는 학습 단계가 없다.

### 4.2 정답 분리
모델 입력은 정답 제거본. 정답은 분리 보관해 **채점에만** 사용. 모델은 자신이 푸는 문항의 정답을 보지 못한다.

### 4.3 해설(③) 제외 사유 — 누수 차단
해설은 정답을 알려준 상태에서 생성했으므로(정답 사전 사용), 본 원칙에 어긋난다. LOO로 자기 문항 해설은
제외했으나(직접 누수 차단), 해설 코퍼스 자체가 전 문항 정답을 간접 내포한다. **또한 효과도 없어(처방형에서
그래프보다 낮음) 최종 결과에서 ③을 제외**한다. **보고하는 향상치(선택적RAG)는 ①+②로만 구성되어 완전히
깨끗하다.**

### 4.4 채점
예측 보기번호==정답. 전체/과목별/유형별 정답률 + Wilson 95% 신뢰구간.

## 5. 제안 — 유형-선택적 RAG (Selective RAG)

**동기:** 지식그래프에는 *처방 정보만* 있어, 보기가 처방명인 **처방형 문항에만** 근거가 유효하다. 비처방형
문항(개념·법규·기전 등)에는 무관한 처방 근거가 **오히려 방해**가 된다.

**규칙(고정, 누수 없음):**
```
if 문항이 "치방은?/처방은?" (처방형):  답 = 그래프RAG(②)
else (그 외):                          답 = 그냥LLM(①)
```
이는 문항 유형(텍스트 패턴)만 보고 결정하며 정답을 보지 않는다. 사전 계산된 ①·② 예측을 사후 결합하므로
**추가 추론 불필요**.

### 6.3 핵심 발견 — GraphRAG 효과는 강하게 **모델 의존적**

- **qwen2.5가 압도적 수혜**: 처방형 **+15.1%p**, 선택적RAG 전체 +2.5%p. 한자·중국어 코퍼스에 강해 처방의
  한자 구성·주치 근거를 실제로 활용.
- **gemma2 소폭**(처방형 +3.5%p), **exaone·llama·solar 미미**(+1.2%p), **mistral 역효과**(처방형 −8.1%p).
- 즉 **GraphRAG 이득 ∝ 모델의 한자/한의학 도메인 이해력.** 영어권 모델(mistral)은 한자 근거를 못 살려 오히려 방해.
- **선택적RAG는 거의 모든 모델에서 그냥LLM 이상**(역효과 모델도 처방형만 그래프 적용 시 손해 최소화) — 단,
  근거를 못 쓰는 모델(mistral)은 처방형에서도 손해라 선택적RAG도 −1.4%p. **모델별로 RAG 적용 여부를 정해야 함**을 시사.

## 7. 논의 / 발견

1. **GraphRAG는 "처방형"에서만 효과적이다.** 전체 평균으론 희석되어 평평하지만(처방형은 17%뿐), 유형을
   분리하면 처방형에서 큰 향상이 드러난다. 이는 검색 근거의 **도메인 적합성**이 효과를 좌우함을 보인다.
2. **유형-선택적 적용이 핵심.** 무관한 근거의 방해를 제거하고 유효한 근거만 살리면 전체 정확도가 오른다.
3. **강한 LLM 기저 + 낮은 검색 recall**: 비처방형은 모델이 이미 잘 풀고(폐쇄형 ~53%), 처방형은 모델이 약해
   외부 처방 지식의 이득이 크다.
4. 원본(gpt-4o-mini)과 일관: RAG는 만능이 아니라 **근거가 정답을 정확히 담을 때만** 효과.

## 8. 한계 (정직한 기재)

- **처방형 n=86**으로 작아 CI가 넓다(향상은 일관되나 점추정은 지시적).
- 지식그래프 **증상→처방 검색 recall이 낮다**(원본 4.7%) — 그래서 보기 기반 조회(보기Graph)가 핵심.
- 그래프는 **내과 처방 중심**이라 본초·침구·법규 등은 직접 근거가 없다(그 영역은 선택적RAG에서 그냥LLM 사용).
- 비전 전사 기반 데이터의 드문 오탈자 가능. 단일 회차(한의사81·한약사27)만 포함.
- 로컬 모델은 긴 근거 프롬프트에서 형식 이탈(번호 미출력) 일부 발생 → 미파싱은 오답 처리(보수적).
