# GraphRAG 데이터 출처 (provenance)

본 `graphrag/` 의 모든 RAG 지식원과 그로부터 생성한 근거 데이터를 **출처와 함께** 저장한다.
국가고시 기출·표준용어집·교과서 데이터는 저작권 보호 대상이며 **개인 학습·연구용**으로만 사용한다.

## 1. 원천 지식 데이터 (KTM-LLM `bigse0u1` 브랜치에서 이관)

| 파일 | 내용 | 규모 | 출처 |
|---|---|---|---|
| `data/kg_all_nodes.jsonl` | 지식그래프 노드(처방·약재·증상·변증·장부·계통) | 7,692 | 아래 처방·용어·진료지침으로 구축 |
| `data/kg_all_edges.jsonl` | 지식그래프 엣지(구성·주치·귀경·계통·팔강귀속 등) | 39,996 | 동일 |
| `data/처방_rag_chunks.jsonl` | 처방별 주치·구성·출전 본문 + 메타(출전·페이지) | 3,094 | **한국한의학연구원 한의대 내과학 교과서 처방 데이터(2024)** |
| `data/처방_rag_chunks_clinical.jsonl` | 처방 임상표현 재작성 청크 | 2,213 | 위 처방 데이터를 LLM이 임상문체로 재작성 |
| `data/한의학용어_rag_chunks.jsonl` | 한의학 표준용어 정의 본문 + 메타 | 9,074 | **표준한의학용어집(2006, 대한한의학회)** |

- 처방 노드/청크 메타: `출전`(入門·醫鑑·金匱要略·東醫寶鑑 등 원전), `출처`(간계/심계/비계/폐계/신계 내과학),
  `페이지`, `source`(한국한의학연구원 한의대 내과학 교과서 처방 데이터 2024).
- 팔강변증(증상→변증) 매핑: **팔강변증 한의표준임상진료지침(2023)**.

## 3. 본 작업에서 생성·저장한 RAG 근거 (출처 포함)

| 파일 | 내용 | 생성법 |
|---|---|---|
| `data/per_question_evidence.jsonl` | **517문항별 그래프 근거**(보기 처방의 구성·주치·계통·출전 + 증상부합 처방 후보) + `sources`(간계내과학 등 출처) | `build_evidence.py` 가 위 처방 KG/청크에서 Neo4j 없이 순수 Python으로 retrieve |

- 각 줄: `{idx, 과목, evidence, 보기처방_매칭[], 증상시드[], sources[]}` — **근거마다 출처를 명시**해 저장.
- 즉 "RAG로 수집·사용한 데이터"는 원천(1)과 문항별 근거(3) 모두 레포에 보존된다.

## 4. 임베딩/그래프 엔진(원 파이프라인, 참고)

- 그래프 DB: Neo4j Community(로컬), 벡터 DB: Chroma, 임베딩: `BAAI/bge-m3`(무료, 로컬).
- 본 `build_evidence.py` 는 Neo4j 없이도 그래프 근거를 재현(이식성) — `step1~4_*.py` 는 원 파이프라인 보존용.

> 출처 표기 요약: 표준한의학용어집(2006) · 한의대 내과학 교과서 처방 데이터(2024) · 팔강변증 한의표준임상진료지침(2023) · 국시원 공개 기출(한의사81·한약사27).
